# HandDraw-Hand-Gesture-Based-Drawing-with-OCR-Shape-Detection
This project enables users to **draw in the air using their hand** detected via webcam and recognize either the **text written** using Tesseract OCR or **shapes drawn** using OpenCV-based contour analysis. It integrates MediaPipe for hand tracking and uses real-time webcam feed.
🎯 Features

- ✋ Real-time **hand tracking** using MediaPipe
- 🖊️ Air **drawing with index finger**
- 🧼 **Eraser mode** when all 5 fingers are shown
- 📝 Convert hand-drawn text into **digital text using OCR**
- 🔺 Detect basic **shapes** like Circle, Triangle, Square
- 🎥 Live drawing with **visual feedback**
- 🖥️ Simple **keyboard control**:
  - `r` ➜ Recognize Text
  - `s` ➜ Recognize Shape
  - `q` ➜ Quit App

---

## 🧠 Tech Stack

- Python 3.x
- OpenCV
- MediaPipe
- NumPy
- PyTesseract (Tesseract OCR)
